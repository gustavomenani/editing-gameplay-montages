These hold in BOTH styles, they outrank a reference video where the two disagree, and they outrank the defaults. Every row is a real
complaint from a delivered version; the last column says where the skill enforces it (or that it is your judgement).

## How to use this page

- When two instructions disagree, this page wins; when it is silent, the reference video wins over the defaults.
- A user's new words win over this page: quote them in `LEIAME.md` and follow them.
- If a request would break one of these rules, say so in one line and offer the closest thing that does not (never silently do it).
